# 微服务与分布式 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 注册配置 | Nacos | 注册 + 配置一体 |
| 网关 | Spring Cloud Gateway | 统一入口 |
| 调用 | OpenFeign | 声明式调用 |
| 容错 | Sentinel | 限流熔断 |
| 事务 | Seata | 分布式事务 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **服务边界**：如何拆分才合理
- **服务通信**：同步 RPC vs 异步消息
- **容错设计**：超时、重试、降级
- **可观测**：链路追踪与日志聚合

## 学习路径

1. 先把单体拆成两个服务
2. 再引入网关与注册中心
3. 最后加限流与链路追踪
