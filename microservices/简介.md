# 微服务与分布式 · 简介

> Spring Cloud 微服务拆分与治理

## 能做什么

- 服务注册与发现
- API 网关与路由
- 配置中心与热更新
- 限流熔断降级
- 分布式事务

## 适合的项目

- **中大型系统拆分**：多服务协作
- **多团队并行**：边界清晰
- **内部平台**：统一治理

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：OpenJDK 17、Maven、Spring Cloud Alibaba（依赖需下载）
- 注意：本机单机可跑轻量微服务；完整治理需多实例，注意内存占用

## 快速开始

```bash
mvn -pl gateway spring-boot:run
mvn -pl user-service spring-boot:run
# Nacos 需先启动
```
