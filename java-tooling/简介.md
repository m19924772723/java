# Java 命令行工具与批处理 · 简介

> Java 命令行工具与批处理程序

## 能做什么

- CLI 工具与子命令
- 批量文件处理
- Excel 报表读写
- 数据导入导出
- 定时批处理作业

## 适合的项目

- **内部工具**：批处理与转换
- **数据导出**：报表生成
- **批处理作业**：定时跑

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：OpenJDK 17、Maven、Picocli（需引依赖）、EasyExcel / Hutool
- 注意：可用 jpackage 打成免装可执行文件

## 快速开始

```bash
mvn archetype:generate -DartifactId=tool
mvn package
java -jar target/tool.jar --help
```
