# Java 命令行工具与批处理 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| CLI | Picocli | 注解式命令 |
| 工具 | Hutool | 常用工具集 |
| Excel | EasyExcel / POI | 大文件读写 |
| 构建 | Maven / Gradle | 依赖管理 |
| 打包 | jpackage / Shadow | 免装可执行 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **参数解析**：选项与子命令
- **文件 IO**：NIO 与流式处理
- **大文件**：流式避免 OOM
- **打包分发**：Fat Jar 与 jpackage

## 学习路径

1. 先写一个读参数的 Java 程序
2. 再抽成 CLI 工具
3. 最后打包分发
