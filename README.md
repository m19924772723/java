# Java — 后端服务与企业应用

**定位**：Spring 类后端、命令行工具、企业级系统

**本机状态**：✅ 可直接开发

**工具链**：OpenJDK 17（PATH）+ JDK 1.8（JAVA_HOME）；Maven 3.6.1

**建议技术栈**：Java 17、Maven、Spring Boot

**注意**：⚠️ JAVA_HOME 指向 Java 8，与 PATH 上的 17 不一致，构建前先统一版本
