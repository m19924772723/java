# Spring Boot 后端服务 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | Spring Boot 3 | 约定优于配置 |
| 数据 | Spring Data JPA / MyBatis-Plus | ORM 与 SQL 双选 |
| 安全 | Spring Security / Sa-Token | 鉴权与权限 |
| 工具 | Hutool / Lombok | 提升开发效率 |
| 文档 | Knife4j / Swagger | 接口即文档 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **IoC 与 AOP**：依赖注入与切面
- **三层架构**：Controller / Service / Mapper
- **统一响应与异常**：Result 与全局处理
- **配置管理**：多环境 profile

## 学习路径

1. 先写一个 REST 接口
2. 再加数据库与分层
3. 最后加鉴权、文档与部署
