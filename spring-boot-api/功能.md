# Spring Boot 后端服务 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 接口

- **CRUD**：增删改查
- **分页与条件查询**：通用列表
- **参数校验**：注解式校验

## 数据

- **ORM 映射**：实体与表
- **事务**：@Transactional
- **连接池**：Druid / Hikari

## 安全

- **鉴权**：Token / Session
- **权限**：接口级控制
- **审计日志**：操作留痕

## 运维

- **多环境配置**：dev / prod
- **健康检查**：Actuator
- **打包部署**：Jar 与 Docker

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
