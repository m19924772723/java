# Spring Boot 后端服务 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · Hello API

- **目标**：跑通
- **产出**：可访问的接口

- [ ] 建 Spring Boot 项目
- [ ] 写第一个 Controller
- [ ] 本地启动验证

## 阶段二 · 分层与数据

- **目标**：结构清晰
- **产出**：带数据库的服务

- [ ] 三层拆分
- [ ] 接入 ORM
- [ ] CRUD 接口

## 阶段三 · 安全与文档

- **目标**：可对外开放
- **产出**：带鉴权的接口

- [ ] 鉴权与权限
- [ ] 全局异常
- [ ] 接口文档

## 阶段四 · 部署

- **目标**：可交付
- **产出**：上线的服务

- [ ] 多环境配置
- [ ] 打包 Jar
- [ ] 健康检查与日志

---

### 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| 阶段一 · Hello API | 可访问的接口 |
| 阶段二 · 分层与数据 | 带数据库的服务 |
| 阶段三 · 安全与文档 | 带鉴权的接口 |
| 阶段四 · 部署 | 上线的服务 |

> 建议：每完成一个阶段就在本目录下建一个具体项目子目录，把成果固化下来。
