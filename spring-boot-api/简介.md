# Spring Boot 后端服务 · 简介

> 用 Spring Boot 快速构建生产级 REST 服务

## 能做什么

- REST 接口与 CRUD
- 鉴权与权限控制
- 参数校验与全局异常
- 接口文档与联调
- 定时任务与异步

## 适合的项目

- **业务后台接口**：给前端 / App 调用
- **企业内部服务**：稳定可靠
- **管理 API**：后台与运维

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：OpenJDK 17（PATH）+ JDK 1.8（JAVA_HOME）、Maven 3.6.1
- 注意：⚠️ 本机 JAVA_HOME 指向 Java 8、PATH 是 Java 17，Maven 默认吃 8，注意统一版本

## 快速开始

```bash
mvn archetype:generate -DgroupId=com.demo -DartifactId=api
cd api && mvn spring-boot:run
# 打开 http://127.0.0.1:8080
```
