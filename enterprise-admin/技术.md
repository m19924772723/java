# 企业后台与权限系统 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | Spring Boot + MyBatis-Plus | 快速 CRUD |
| 鉴权 | Sa-Token / Spring Security | RBAC |
| 缓存 | Redis | 会话与权限缓存 |
| 前端 | Vue 3 + Element Plus | 后台界面 |
| 文档 | 代码生成 + Swagger | 提效 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **RBAC 模型**：用户-角色-权限-菜单
- **数据权限**：行级 / 列级控制
- **多租户**：数据隔离策略
- **审计**：操作与登录日志

## 学习路径

1. 先跑通一个后台脚手架
2. 再理解权限模型
3. 最后做多租户与数据权限
