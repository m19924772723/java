# 企业后台与权限系统 · 简介

> 企业后台管理系统与 RBAC 权限体系

## 能做什么

- 用户 / 角色 / 菜单权限
- 数据字典与配置
- 操作日志与登录日志
- 代码生成器
- 报表与统计

## 适合的项目

- **后台管理系统**：内部运营
- **多租户 SaaS**：租户隔离
- **企业内部平台**：权限管控

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Spring Boot + MyBatis-Plus + Sa-Token；前端 Vue（可选）；MySQL / Redis 已就绪
- 注意：可参考若依（RuoYi）等成熟脚手架快速起步

## 快速开始

```bash
git clone https://github.com/YunaiV/ruoyi-vue-pro
mvn clean package -DskipTests
java -jar target/*.jar
```
