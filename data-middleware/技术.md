# 数据中间件与消息队列 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 消息 | Kafka / RocketMQ | 高吞吐 / 事务消息 |
| 缓存 | Redis / Redisson | 缓存与分布式锁 |
| 检索 | Elasticsearch | 全文与聚合 |
| 调度 | XXL-Job | 分布式任务 |
| 客户端 | Spring Boot Starter | 快速集成 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **消息模型**：生产者、消费者、分区与顺序
- **可靠性**：确认、重试、幂等消费
- **缓存策略**：更新与失效、防穿透
- **索引设计**：Mapping 与分词

## 学习路径

1. 先用 Redis 做一个缓存
2. 再引入消息队列解耦
3. 最后加检索与调度
