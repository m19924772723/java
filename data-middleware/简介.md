# 数据中间件与消息队列 · 简介

> 消息队列、缓存与搜索中间件的应用

## 能做什么

- 异步解耦与削峰
- 消息可靠投递
- 缓存加速与一致性
- 全文检索
- 分布式定时任务

## 适合的项目

- **数据同步**：跨系统搬运
- **日志 / 行为采集**：异步写入
- **搜索服务**：全文检索

## 本机环境

- 本机状态：✅ 可直接开发（部分需装）
- 工具链：MySQL 8 已运行、Redis 已运行；Kafka / RocketMQ / ES 需按需安装
- 注意：本机已有 MySQL 与 Redis；Kafka / ES 较重，注意内存

## 快速开始

```bash
docker run -d -p 9092:9092 apache/kafka
docker run -d -p 9200:9200 docker.elastic.co/elasticsearch/elasticsearch:8
# 用客户端连测试
```
