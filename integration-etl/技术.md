# 系统集成与数据同步 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 批处理 | Spring Batch | 作业与分片 |
| 集成 | Camel | 路由与转换 |
| ETL 引擎 | DataX / SeaTunnel | 高性能同步 |
| 调度 | XXL-Job / 计划任务 | 定时触发 |
| 校验 | 数据质量规则 | 一致性 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **ETL 三阶段**：抽取、转换、加载
- **增量策略**：时间戳 / 自增 ID / 日志
- **幂等与重放**：失败可重跑
- **数据质量**：行数、主键、空值校验

## 学习路径

1. 先做一次全量同步
2. 再做增量与断点续传
3. 最后加质量校验与告警
