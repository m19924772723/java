# 系统集成与数据同步 · 简介

> 多系统接口对接与 ETL 数据同步

## 能做什么

- 多源数据抽取
- 清洗转换
- 批量加载入库
- 第三方接口对接
- 增量同步

## 适合的项目

- **数据中台**：汇聚多源
- **系统对接**：打通孤岛
- **报表数据准备**：定时同步

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：OpenJDK 17、Maven、DataX / SeaTunnel（可选）、MySQL 已就绪
- 注意：本机可跑单机 ETL；大规模同步建议用专业引擎

## 快速开始

```bash
mvn package
java -jar job.jar --config etl.yml
# 查看同步日志与行数
```
