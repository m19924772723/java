# Android 原生（Java） · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 语言 | Java | 经典稳定 |
| 网络 | Retrofit + OkHttp | 标准组合 |
| 存储 | Room / SQLite | 本地数据库 |
| 图片 | Glide | 加载与缓存 |
| 构建 | Gradle | 依赖与打包 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **四大组件**：Activity / Service / Broadcast / ContentProvider
- **生命周期**：Activity 与 Fragment
- **异步**：线程与 Handler
- **权限**：运行时权限申请

## 学习路径

1. 先跑通 Hello World
2. 再做一个列表 + 详情
3. 最后加网络与本地存储
