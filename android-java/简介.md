# Android 原生（Java） · 简介

> 用 Java 开发 Android 原生应用

## 能做什么

- 原生界面与列表
- 网络请求与接口对接
- 本地存储与数据库
- 权限与通知
- 打包与签名发布

## 适合的项目

- **工具类 App**：轻量实用
- **企业内部 App**：内部使用
- **硬件联动 App**：设备对接

## 本机环境

- 本机状态：✅ 可直接开发（IDE 按需）
- 工具链：Android SDK（platforms 35/36 + build-tools + adb）、Java 17、Gradle
- 注意：本机有 SDK 与 adb，缺 Android Studio（可选装）

## 快速开始

```bash
sdkmanager "platforms;android-35"
gradle assembleDebug
adb install app-debug.apk
```
