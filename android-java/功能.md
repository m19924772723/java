# Android 原生（Java） · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 界面

- **列表 / 详情**：RecyclerView
- **表单**：输入与校验
- **适配**：多分辨率

## 数据

- **网络请求**：Retrofit
- **本地存储**：Room
- **缓存**：图片与接口

## 能力

- **通知**：本地推送
- **权限**：运行时申请
- **设备能力**：相机 / 定位

## 发布

- **签名打包**：APK / AAB
- **多渠道**：区分环境
- **上架**：应用市场

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
